# Connectify

Connectify is a full-stack social networking platform designed for developers, IT students, software engineers, and technology professionals.

The platform allows users to create profiles, share posts, interact with other users, build connections, and receive real-time notifications.

## Project Overview

Connectify is being developed as part of the Rhombix Technologies internship program.

The project focuses on building a modern social networking platform with real-world features such as user profiles, posts, comments, likes, friend requests, real-time notifications, privacy controls, and multimedia content sharing.

## Planned Features

- User Registration and Login
- JWT Authentication
- User Profiles
- Edit Profile
- Create, Edit and Delete Posts
- Image and Video Sharing
- Like and Unlike Posts
- Comments and Replies
- Friend Requests
- Accept and Reject Friend Requests
- Friends / Connections
- Real-Time Notifications
- WebSocket Communication
- Privacy Settings
- Search and Explore
- Responsive Design
