# Personal Portfolio

A modern, responsive personal portfolio website built to showcase my skills, projects, education, experience, and professional background as a Full Stack MERN Developer.

## About

This portfolio represents my journey as a web developer and highlights the technologies, projects, and experience I have gained throughout my development journey.

The website is designed with a clean and modern interface, responsive layouts, smooth navigation, interactive elements, and dark and light theme support.

## Features

- Modern and responsive user interface
- Dark and light theme
- Hero section with professional introduction
- About Me section
- Technology Stack section
- Projects showcase
- Education section
- Experience section
- Contact section
- Social media and professional links
- Smooth scrolling navigation
- Interactive hover effects
- Framer Motion animations
- Mobile-friendly design
