### Task 03 — GlideAway

**GlideAway** is a full-stack **Travel Booking System** developed using **React.js, Node.js, Express.js, and MongoDB**.

The project provides a responsive travel platform where users can explore destinations, search properties, view rooms and deals, create accounts, and make travel reservations.

**Technologies:**
- React.js
- Vite
- JavaScript
- CSS3
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Axios
- REST APIs

**Features:**
- Modern travel landing page
- Destination exploration
- Hotel, resort, villa, and apartment listings
- Property details
- Room information
- Search and filtering
- Price and rating filters
- Travel deals
- User registration and login
- JWT-based authentication
- Protected booking functionality
- Travel reservations
- MongoDB database
- RESTful backend APIs
- Responsive design
- Payment interface

> **Note:** Payment gateway integration was an optional requirement. GlideAway includes the payment/booking interface, but a real online payment gateway and payment-processing backend were not implemented.

📁 **Project Folder:** [`GlideAway`](./GlideAway)

### Task 04 — QuickBite

**QuickBite** is a full-stack **Online Food Ordering Platform** developed using **React.js, Node.js, Express.js, and MongoDB**.

The application allows customers to discover restaurants, browse menus, customize food items, manage their carts, place orders, and view their order history. It also includes an admin dashboard for managing the platform.

🔗 **Main Repository:** [QuickBite — Online Food Ordering Website](https://github.com/alisha-tech21/quickbite_online_food_ordering_website)

**Technologies:**
- React.js
- Vite
- JavaScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cloudinary
- REST APIs
- Playwright

**Customer Features:**
- User registration and login
- OTP-based account recovery
- Restaurant discovery
- Restaurant search and filtering
- Menu browsing
- Food item customization
- Cart management
- Checkout functionality
- Cash on Delivery (COD)
- Order history
- Eligible order cancellation
- Offers and vouchers

**Admin Features:**
- Dashboard and order statistics
- Order management and status updates
- User management
- Restaurant management
- Menu item management
- Voucher management
- Review management
- System settings

**Testing:**
- Frontend automated tests
- Backend API tests
- End-to-end tests using Playwright

> **Payment Note:** Cash on Delivery is supported in the tested checkout flow. Live online payment gateway processing has not yet been implemented.

**Project Links:**
- 🎨 **Frontend:** [QuickBite Frontend Code](https://github.com/alisha-tech21/quickbite_online_food_ordering_website/tree/main/quickbite-frontend)
- ⚙️ **Backend:** [QuickBite Backend Code](https://github.com/alisha-tech21/quickbite_online_food_ordering_website/tree/main/quickbite-backend)
- 🌐 **Complete Project:** [View QuickBite on GitHub](https://github.com/alisha-tech21/quickbite_online_food_ordering_website)
