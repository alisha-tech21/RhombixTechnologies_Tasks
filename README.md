### Task 02 — Connectify

**Connectify** is a full-stack social networking web application developed using the **MERN stack**.

The application allows users to create profiles, share posts, interact with other users, send friend requests, receive notifications, and communicate through real-time messaging.

**Technologies:**
- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Nodemailer
- Socket.IO
- Cloudinary
- REST APIs

**Features:**
- User registration and login
- Email verification
- Password reset
- User profiles
- Create and manage posts
- Image uploads
- Likes and comments
- Friend requests
- Notifications
- Real-time messaging
- Explore users and posts
- Protected routes
- Responsive user interface

📁 **Project Folder:** [`Connectify`](./Connectify)

### Task 03 — GlideAway

**GlideAway** is a full-stack **Travel Booking System** developed using **React.js, Node.js, Express.js, and MongoDB**.

The project provides a responsive travel platform where users can explore destinations, search properties, view rooms and deals, create accounts, and make travel reservations.

**Technologies:**
- React.js
- Vite
- JavaScript
- CSS3
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Axios
- REST APIs

**Features:**
- Modern travel landing page
- Destination exploration
- Hotel, resort, villa, and apartment listings
- Property details
- Room information
- Search and filtering
- Price and rating filters
- Travel deals
- User registration and login
- JWT-based authentication
- Protected booking functionality
- Travel reservations
- MongoDB database
- RESTful backend APIs
- Responsive design
- Payment interface

> **Note:** Payment gateway integration was an optional requirement. GlideAway includes the payment/booking interface, but a real online payment gateway and payment-processing backend were not implemented.

📁 **Project Folder:** [`GlideAway`](./GlideAway)
